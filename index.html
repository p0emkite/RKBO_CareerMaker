GitHub 공용 DB

확인 중

선수 기록과 시즌 설정을 GitHub 저장소의 data/career-db.json에 기록할 수 있어요. 다른 기기에서는 저장된 DB를 토큰 없이 불러올 수 있습니다.

쓰기용 토큰은 화면을 연 동안에만 보관하며, GitHub 파일이나 브라우저 저장소에 저장하지 않습니다.

공개 저장소이므로 업로드한 선수 기록은 누구나 볼 수 있습니다. 저장 전 데이터를 확인해 주세요.

누적 규칙 / 이용 안내

같은 선수 ID·시즌은 중복 추가하지 않고 새 기록으로 갱신합니다. 오래된 시즌 ZIP을 추가하더라도 가장 최근 시즌의 선수 소속팀 및 통산 요약을 보존합니다. 브라우저 DB는 기기별로 저장되므로 JSON 백업을 권장합니다. 서로 다른 리그의 HHRecord 파일은 같은 DB에 섞지 마세요.
